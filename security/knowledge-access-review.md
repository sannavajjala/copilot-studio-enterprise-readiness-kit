# Knowledge Access Review

- [ ] Every knowledge source is inventoried.
- [ ] Source owner approved use by the agent.
- [ ] Source data classification is documented.
- [ ] Agent audience is compatible with source audience.
- [ ] User-specific authorization behavior is understood.
- [ ] Restricted content has been tested with both authorized and unauthorized users.
- [ ] Maker/owner privileges are not mistaken for normal-user behavior.
- [ ] Draft, archived, superseded, or unapproved content is excluded where necessary.
- [ ] Public website sources are reviewed for trust and suitability.
- [ ] Uploaded/static documents have an update/retirement owner.
- [ ] Content changes can be traced to an accountable source owner.
- [ ] Sensitive information in transcripts is considered in monitoring/access design.
