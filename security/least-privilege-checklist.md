# Least-Privilege Checklist

- [ ] Agent is shared only with the required audience.
- [ ] Co-author access is limited to required makers/admins.
- [ ] Environment roles are no broader than required.
- [ ] Service accounts/service principals have minimum connector/API permissions.
- [ ] Read-only permissions are used when write permissions are unnecessary.
- [ ] Delete/admin/elevated permissions are avoided unless essential.
- [ ] Knowledge-source permissions are not broadened solely to make the agent work.
- [ ] Production deployment identity is separated from routine maker identities where appropriate.
- [ ] Analytics/transcript access is restricted.
- [ ] Temporary elevated permissions have expiry/removal steps.
- [ ] Permissions are periodically reviewed.
