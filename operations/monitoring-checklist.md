# Monitoring Checklist

## Agent monitoring
- [ ] Monitoring owner is named.
- [ ] Usage/engagement trends are reviewed.
- [ ] Answer quality and unresolved/poor outcomes are reviewed.
- [ ] User feedback is reviewed where available.
- [ ] Conversation/session details are reviewed under approved privacy controls.
- [ ] Knowledge failures and unexpected responses are tracked.

## Action monitoring
- [ ] Agent-flow/action run failures are monitored.
- [ ] Failure rate and latency trends are reviewed.
- [ ] External API/service outages have a support path.
- [ ] Capacity/quota/rate-limit issues are included in troubleshooting.

## Operational governance
- [ ] Transcript access is limited to authorized roles.
- [ ] Production incidents have severity/response criteria.
- [ ] Owner reviews access and connectors periodically.
- [ ] Knowledge sources have freshness review cadence.
- [ ] Major platform changes trigger regression testing when necessary.
- [ ] Business owner reviews continued value and retirement need.
