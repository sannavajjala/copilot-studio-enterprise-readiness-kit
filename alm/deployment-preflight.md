# Deployment Preflight

Complete immediately before promotion to the next environment.

**Solution:**  
**Version:**  
**Source environment:**  
**Target environment:**

- [ ] Correct source solution/version selected.
- [ ] Required components and dependencies are included.
- [ ] No unintended unmanaged changes exist in target.
- [ ] Target environment capacity/licensing prerequisites are satisfied.
- [ ] Target connection references are mapped.
- [ ] Target environment variables/URLs/IDs are available.
- [ ] Required service accounts/service principals exist in target.
- [ ] Required security roles are assigned.
- [ ] Knowledge sources are reachable from target.
- [ ] Required flows/actions are enabled or have an enablement plan.
- [ ] DLP/data policies in target permit the intended design.
- [ ] Authentication configuration has been reviewed for target.
- [ ] Sharing groups for target are known.
- [ ] Deployment approver is available if approval is required.
- [ ] Rollback method is known before deployment begins.
- [ ] Smoke-test users and scenarios are identified.
