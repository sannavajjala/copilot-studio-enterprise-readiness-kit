# Post-Deployment Validation

Perform after every Test/UAT or Production deployment.

- [ ] Agent exists in the expected target environment.
- [ ] Expected solution version is installed.
- [ ] Agent publishes successfully.
- [ ] Intended channels are enabled.
- [ ] Authentication works for a normal target-environment user.
- [ ] Sharing scope is correct.
- [ ] Knowledge sources return expected authorized content.
- [ ] Restricted users cannot access restricted content.
- [ ] Each critical action executes successfully.
- [ ] Connection references use target-environment connections.
- [ ] Environment-specific URLs/IDs/settings are correct.
- [ ] Flow/action failures are not present in initial smoke testing.
- [ ] Analytics/monitoring begins receiving expected production activity.
- [ ] Support owner has access needed to troubleshoot.
- [ ] Release/change record is updated with result.
