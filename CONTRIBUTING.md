# Contributing

Contributions are welcome: controls, product-change corrections, evidence guidance, anonymized examples, documentation improvements, and authoritative references.

Before a pull request:
1. Search existing issues/PRs.
2. Keep controls practical and testable.
3. Prefer Microsoft Learn for product-specific claims.
4. Explain the risk the control addresses.
5. Never include employer/customer confidential information, credentials, tenant IDs, or personal data.
6. Explain any scoring change.
7. Update `CHANGELOG.md` for user-facing changes.
