# Sharing Review Checklist

- [ ] Intended chat audience is documented.
- [ ] Sharing uses security groups where practical rather than broad individual assignments.
- [ ] Organization-wide sharing is justified and approved.
- [ ] External/public access is explicitly reviewed.
- [ ] Authentication configuration supports the intended access-control model.
- [ ] Collaborators/co-authors are separated from chat-only users.
- [ ] Former project members and temporary collaborators are removed.
- [ ] Analytics access is limited to people who need it.
- [ ] Transcript access is treated as potentially sensitive data access.
- [ ] Underlying flows, connections, SharePoint sites, Dataverse tables, Fabric items, APIs, and other resources have their own permissions reviewed.
- [ ] Testing includes a normal user, not only the maker/owner account.
- [ ] Access review cadence and owner are defined.
